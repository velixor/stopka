# Баги и недостатки

## Баги

- при анимации перехода (sink/collapse) после game over, последний неупавший блок (missed block) двигается за камерой вместо того чтобы уйти с башней

## Визуальные недостатки

- анимация камеры при pullback (показ полной башни на game over) — при высокой башне увеличение и сдвиг выглядят некрасиво
- падающие обрезанные блоки выглядят скучно — падают прямо вниз без вращения, нужно добавить рандомный torque/rotation при отсечении

## Геймплей

- при combo recovery блок увеличивается в случайную сторону (50/50), но хочется чтоб с большей вероятностью увеличивался в ту ось, в которой он меньше
